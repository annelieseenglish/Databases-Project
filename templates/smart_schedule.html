How Smart Scheduling Works

  • Fetches all existing appointments for the selected physician in the date range.
  • Iterates over every weekday in 15-minute increments from 8:00 AM to 5:00 PM.
  • Applies interval overlap detection to exclude conflicting slots.
  • Scores each candidate slot using a weighted function (70% preference alignment, 30% schedule efficiency).
  • Returns the top 5 highest-ranked available slots.

SQL techniques used: interval overlap queries, date-range filtering, ordered result sets.
